## ภาพรวม: ReflexWork ตอนนี้ตัดสินใจ 4 ทาง

```
ข้อความเข้า → 🦀 Reflex Kernel (gate σ, BLAKE3, confidence/abstain)
   ├─ factual (กี่วัน/กี่บาท)      → FastPath ตอบจาก KB ดิบ        0 token · ตัวเลขเป๊ะ
   ├─ advice + KB พอ               → Grounded Hybrid (KB + AI เรียบเรียง)  ground เท่านั้น ไม่มั่ว
   ├─ advice + KB ไม่ตรง (abstain) → ส่ง staff + gap log            ไม่ดันตอบผิด
   └─ personal (login/account/ค้าง)→ Intake form เก็บข้อมูล → staff  ไม่เดา
```

## สิ่งที่ทำวันนี้ (PR #25–#40)

- Gap log (D1) + dashboard backlog + PII masking (counts-first)

## วิธี build/deploy
- KB: แก้ `.md` ใน `submissions/ui/knowledge-public/` → `python3 submissions/build_knowledge_index.py` → regen `kb-data.mjs` → deploy
- `knowledge-index.json` เป็น generated (gitignored) — rebuild ตอน deploy
- Pages: `cd submissions && npx wrangler pages deploy ui --project-name=reflexwork`
- Workers: `cd integrations/<worker> && npx wrangler deploy`
