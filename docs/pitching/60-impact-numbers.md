# Impact Numbers — กรอบคำนวณ (assumption-based, ซื่อสัตย์)

> **ไม่ใช่ตัวเลขวัดจริง** — เป็นกรอบประมาณการจากสมมติฐานที่ระบุชัด เพื่อใส่สไลด์
> Impact. กรรมการถามเมื่อไหร่ ตอบได้ว่า "สมมติฐานคือ X, สูตรคือ Y, ปรับตามจริงได้".
> อ้างใน `40-qa-bank.md` Q3.

## สมมติฐาน (ระบุให้ชัด — ปรับได้)
| ตัวแปร | ค่าสมมติ | ที่มา |
|---|---|---|
| คำถาม/วัน (1 คณะ, ช่วง peak เปิดเทอม) | 300 | ประมาณจากเคสจริง (ปรับได้) |
| สัดส่วน fast-path (ตอบเองได้) | 80% | design projection (live ตอนนี้ 87% จาก 31 เคส) |
| token ต่อการเรียก LLM 1 ครั้ง | ~1,500 | prompt + completion เฉลี่ย |
| ราคา LLM | ~$0.30 / 1M token | Gemini Flash-class เฉลี่ย (ปรับตาม provider) |
| เวลาเจ้าหน้าที่ตอบเอง 1 คำถาม | ~3 นาที | ประมาณ (ค้นหา+พิมพ์+ตรวจ) |

## ผลลัพธ์ (2 มุมที่ impact จริง)

### มุม 1 — ต้นทุน token (เล็ก แต่โตตามสเกล)
- fast-path จับ = 300 × 80% = **240 คำถาม/วัน ไม่แตะ LLM**
- token ประหยัด = 240 × 1,500 × 30 วัน = **~10.8M token/เดือน/คณะ**
- เป็นเงิน ≈ **$3–4/เดือน/คณะ** (เล็กต่อคณะ)
- **แต่สเกลทั้งมหาวิทยาลัย** (~30-40 หน่วยที่มี FAQ) = **~$100-150/เดือน** +
  โตตามปริมาณ (ยิ่งช่วง peak ยิ่งประหยัด) + ถ้าใช้ local Typhoon = **$0 ค่า API**

> 💡 จุดขายต้นทุนที่แท้จริงไม่ใช่ "ประหยัดกี่บาท" แต่คือ **ต้นทุนไม่โตตามจำนวนคำถามซ้ำ**
> — ระบบที่ยิง LLM ทุกครั้ง ค่าใช้จ่ายโตเชิงเส้นกับทราฟฟิก; ReflexWork ตัดส่วนซ้ำออกก่อน.

### มุม 2 — เวลาเจ้าหน้าที่ (impact ที่จับต้องได้กว่า) ★
- ถ้าเดิมเจ้าหน้าที่ตอบเอง 240 คำถาม/วัน × 3 นาที = **720 นาที/วัน ≈ 12 ชม.คน/วัน**
- = งานของเจ้าหน้าที่ **~1.5 คน-วัน** หายไปต่อคณะ ต่อวัน ช่วง peak
- เจ้าหน้าที่เอาเวลาไปทำงานที่ต้องใช้คนจริง (เคสซับซ้อน) แทนตอบคำถามซ้ำ

> **สำหรับกรรมการผู้บริหาร:** มุมเวลาเจ้าหน้าที่ (12 ชม.คน/วัน) สื่อ impact ได้แรงกว่า
> ตัวเลขเงิน ($3/เดือน) — เน้นมุมนี้ในสไลด์.

### มุม 3 — ความเร็ว (ประสบการณ์ผู้ใช้)
- fast-path ตอบ ~ไมโครวินาที (route ~12ns + ค้นคู่มือ) vs LLM 350-800ms/ครั้ง
- ช่วง peak ไม่มีคอขวด เพราะ 80% ไม่ต้องรอ server/LLM เลย (รันในเบราว์เซอร์)

## ประโยคใช้บนสไลด์ Impact (เลือก 1-2)
- "คัดคำถามซ้ำ ~80% ออกจาก AI — **ต้นทุนไม่โตตามทราฟฟิก**"
- "ช่วง peak: คืนเวลาเจ้าหน้าที่ **~12 ชม.คน/วัน/คณะ** ไปทำงานที่ต้องใช้คนจริง"
- "ตอบทันทีระดับไมโครวินาที — ไม่มีคอขวดช่วงเปิดเทอม"

> ⚠️ ทุกตัวเลขติดป้าย "ประมาณการจากสมมติฐาน" — อย่านำเสนอเป็นผลวัดจริง.
