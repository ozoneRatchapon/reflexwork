1. เกณฑ์ น้ำหนัก และสิ่งที่ต้องพูด

เกณฑ์คะแนนพูดอะไร (เปิดด้วยข้อนี้)อย่าพูดว่า
Impact / คุณค่าต่อมหาวิทยาลัย25ลดงานซ้ำ ~80% ออกจาก LLM · ตรวจสอบย้อนหลังได้ 100% (PDPA) · ใช้ภาษาธุรกิจ/ผู้บริหารก่อนศัพท์เทคนิค"AI ฉลาดขึ้น" (ไม่มีตัวเลขรองรับ)
Implementation Readiness20ใช้งานจริงบน production แล้ว · ยิงสดได้ · มี production-hardening · มี roadmap ขยายระบบ"พร้อมรองรับผู้ใช้จำนวนมาก" (ยังไม่เคยทดสอบโหลด)
AI + Kiro อย่างมีประสิทธิภาพ15spec-driven (3 specs) · WASM kernel · LLM ที่ยึดกับเอกสาร (grounded) · hooks/CIระบุบทบาท Kiro เกินจริง (ต้องยืนยันกับคุณณภัทรก่อน)
นวัตกรรม / ความคิดสร้างสรรค์15"คัดก่อนเรียก AI = 0 token" · หลักฐาน BLAKE3 ตรวจสอบได้ (System One)"ไม่มีคู่แข่ง"
คุณภาพ Prototype + การสาธิต15เดโมสด 3 ช่วง · วิดีโอ 46 วินาทีสำรองถ้าเน็ตล่ม · แท็บ ?ai=off สำรอง"ไม่แก้สด" ถ้าสะดุด ให้ข้ามไปขั้นถัดไป
การนำเสนอ + ตอบคำถาม10สคริปต์ 5 นาที (จบที่ 4:45) · Q&A bank (ไฟล์ 40)คำตอบที่ไม่รู้ ให้บอกว่า "ไม่เดา" แล้วจดไว้
Impact 25 + Readiness 20 = 45 คะแนน มาเป็นอันดับแรก · กรรมการ 7 ท่านมาจากผู้บริหาร วิชาการ และอุตสาหกรรม

2. ข้อจำกัดที่ต้องพูดก่อนกรรมการถาม

  • อังกฤษถูกต้อง 49% (35/71) · ไทยถูกต้องสูงกว่า
  • FAQ ที่คู่มือยังไม่มี 14 ข้อ · ในจำนวนนี้ไทยตอบผิดหัวข้อ 10 ข้อ (ยังไม่เผยแพร่ ไม่อยู่ใน live manual)
  • 94% คือ อัตราที่ระบบจับคู่ได้ ไม่ใช่อัตราตอบคำถามใหม่ได้ถูกต้อง
  • ตอบเองได้ 44/52 ข้อ · ผิด 3 ข้อ
  • ยังไม่มีการทดสอบโหลด · ยังไม่มีผู้ใช้จริงเป็นวงกว้าง · ความจุ โควตา Cloudflare และ Gemini ยังไม่ได้วัด

3. คำถามกรรมการที่น่าจะถาม

คำถามตอบสั้นๆ
ใช้ผู้ใช้จริงกี่คน / ผลตอบรับ?ยังไม่มีผู้ใช้จริงวงกว้าง · ระบุตามจริง แล้วเสนอ pilot
รองรับคนพร้อมกันได้เท่าไร?ยังไม่ได้วัด · ไม่เคยทดสอบโหลด
ข้อมูลส่วนบุคคล (PDPA) ทำอย่างไร?ตรวจสอบย้อนหลังได้ด้วย BLAKE3 · ขอบเขตคำถามส่วนตัวสำหรับ LINE ยังไม่ได้สร้าง (ต้องบอกตรงๆ)
ใครเป็นเจ้าของคำตอบ / ความถูกต้อง?เจ้าหน้าที่ตรวจสอบก่อนเผยแพร่ · ระบบไม่เดาเมื่อไม่มีในคู่มือ
Kiro ช่วยอะไรจริง?spec-driven 3 specs · ต้องยืนยันรายละเอียดกับทีมก่อนพูด

4. ลำดับความสำคัญเมื่อเวลาจำกัด

  1. Impact และ Readiness (45 คะแนน) — พูดก่อนและพูดให้ชัด
  2. เดโมสดที่เสถียร + วิดีโอสำรอง (15)
  3. ข้อจำกัดที่พูดเอง (ป้องกันการเสียคะแนนจากคำถาม)
  4. Kiro และนวัตกรรม (30 รวม) — เล่าสั้นๆ ตามที่ตรวจแล้วเท่านั้น
