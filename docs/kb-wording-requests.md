# ขอแก้ถ้อยคำในคู่มือ 8 หัวข้อ (ไม่แก้ข้อเท็จจริง)

**ที่มา:** เจ้าหน้าที่บัณฑิตวิทยาลัยลองใช้เมื่อ 3 พ.ย. 2569 แล้วบอกว่าคำตอบ "ตอบแบบแปลก ๆ เป็นพารากราฟยาว อ่านยาก"
ส่วน "พารากราฟยาว" เราแก้ที่การแสดงผลแล้ว (แบ่งเป็นข้อ ๆ ข้อยาวพับไว้ใต้ "อ่านเพิ่ม" โดยถ้อยคำในคู่มือไม่เปลี่ยน)
ส่วน "แปลก ๆ" มาจากประโยคใน 8 หัวข้อนี้ ซึ่ง**เขียนถึงระบบหรือผู้ตรวจ ไม่ได้เขียนถึงนักศึกษา** เช่น "ให้ผู้ใช้…" "FAQ หน่วยงานอธิบายว่า…" "ไม่สมมติว่า…"

หัวข้อเหล่านี้เจ้าของงานอนุมัติแล้ว ทีมจึง**ไม่แก้เอง** ขอให้เจ้าของงานเลือกได้ว่าจะ (ก) ใช้ถ้อยคำที่เสนอ (ข) แก้เอง หรือ (ค) คงไว้
ข้อความที่เสนอใช้ข้อเท็จจริงเดิมทั้งหมด ตัดเฉพาะคำสั่งถึงระบบ แล้วเขียนใหม่ให้พูดกับนักศึกษา
การแก้ถ้อยคำคำตอบ**ไม่กระทบการค้นหา** เพราะดัชนีค้นจากชื่อหัวข้อและคำค้น (`submissions/build_knowledge_index.py`)
