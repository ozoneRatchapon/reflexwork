Reflex Kernel ตัวจริง รันในเบราว์เซอร์ (WebAssembly)

🦀 Rust kernel → WebAssembly
  • algorithm เดียวกับฝั่ง server เป๊ะ (sigmoid gate θ=0.72, seeded weights)
  • ไม่มี backend · ไม่มี network call · ข้อมูลไม่ออกจากเครื่องผู้ใช้
  • พิมพ์งาน → เห็น route decision + BLAKE3 proof ภายในไมโครวินาที
  • แชร์เป็น URL เดียว กรรมการ/ผู้ใช้ทั่วไป "กดลองได้เลย"
🌐 reflexwork.pages.dev/try.html — กดลองได้เลย

route_task("ComplianceCheck", input, 2048, 128)

// รันในเบราว์เซอร์ 100% — ไม่มี server

  "route"        : "FastPath",

Roadmap: จาก public knowledge สู่บริการเฉพาะบุคคล

Tier 1 · วันนี้
Public knowledge — zero backend
คู่มือ/ประกาศที่เหมือนกันทุกคน เก็บเป็น markdown + git → build เป็น index → ตอบในเบราว์เซอร์ (WASM) ฟรี ไม่มี PII cache ได้
Tier 2 · ถัดไป
Personalized — ต้อง login + database
คำถามเฉพาะตัว ("คำร้องของฉันถึงขั้นไหน") ต่อ REST API ที่ auth แล้ว + database (row-level isolation, encrypt at rest) — PII ไม่มีวันอยู่ใน static/WASM ตาม PDPA
