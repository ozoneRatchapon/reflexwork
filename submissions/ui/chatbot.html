🦀 ReflexWork ถามคำถาม ตัวอย่างระบบคัดแยกคำร้อง เบื้องหลังระบบ
บัณฑิตวิทยาลัย มหาวิทยาลัยมหิดล · ผู้ช่วยตอบคำถาม (ต้นแบบ)

ถามเรื่องเรียนต่อ ลงทะเบียน และวิทยานิพนธ์

ถามเรื่องสมัครเรียน ค่าเทอม และการส่งวิทยานิพนธ์ — ตอบจากประกาศและคู่มือทางการ ไม่เดา ถ้าไม่แน่ใจจะบอกและพาไปหาเจ้าหน้าที่

🦀 ตั้งใจฟัง
🗺️ ระบบทำงานยังไง (จากคำถาม → คำตอบ)กดเพื่อดู · มีสวิตช์ดูเบื้องหลังเทคนิค
👤 ผู้ใช้
1. พิมพ์คำถาม เช่น "ส่ง Turnitin เกิน 25% ทำยังไง"
✓ เห็นคำตอบทันที (+ ปุ่มติดต่อเจ้าหน้าที่ถ้าต้องส่งต่อ)
หน้าเว็บเรียก kernel ที่คอมไพล์เป็น WebAssembly ค้นคู่มือในเบราว์เซอร์ · คำถามที่ตอบไม่ได้ถูกบันทึก (ซ่อนข้อมูลส่วนตัว) และบางคำถามส่งให้ AI เรียบเรียง
🦀 ตัวคัดกรอง
2. รับคำถาม → ถามตัวเองว่า "เคยตอบเรื่องนี้ได้ไหม?"
→ เคย (เจอในคู่มือ) → ตอบเลย ฟรี · เร็วมาก
→ ไม่แน่ใจ → ส่งต่อ + บันทึกไว้ปรับปรุงคู่มือ
kernel gate (sigmoid, θ=0.72) จัดเส้นทางงาน — การตัดสินว่าตอบเอง/ส่งต่อใช้คะแนนค้นคู่มือ TF-IDF cosine + lexical overlap (recall@1 86% / @3 96%, eval 50 เคส) · ทุกคำถามที่เข้า kernel มีรหัส BLAKE3 ของคำถาม+เส้นทาง ถามซ้ำได้ค่าเดิม · เส้นทางเร็ว 0 token · ~1.9 µs (gate + รหัส, WASM)
🤖 AI / เจ้าหน้าที่
3. เฉพาะคำถาม ใหม่จริง (ประมาณการ ~20%) เท่านั้นที่มาถึงชั้นนี้
· AI ช่วยร่างจากคู่มือ (ห้ามแต่งเอง) หรือเจ้าหน้าที่ดูแลต่อ
เรียก LLM เฉพาะ escalate ด้วย prompt "ห้ามแต่งนอก KB" · คำถามที่ตอบไม่ได้เข้า gap log → ปรับคู่มือ ไม่เทรนโมเดลใหม่
💡 คำถามซ้ำ ๆ ส่วนใหญ่จบที่ชั้น 🦀 โดยไม่แตะ AI — ถูก เร็ว ตรวจสอบย้อนหลังได้
กำลังโหลด Reflex Kernel (WASM) ในเบราว์เซอร์…
คำถามที่ตอบไม่ได้จะถูกบันทึกให้ทีมคู่มือ (ซ่อนอีเมลและเลขรหัสก่อนส่ง) · อย่าพิมพ์ข้อมูลส่วนตัวในแชต · ประวัติแชตเก็บในแท็บนี้เท่านั้น (ปิดแท็บแล้วหาย ไม่ส่งขึ้นเซิร์ฟเวอร์) · เติม ?ai=off ท้าย URL เพื่อไม่ส่งให้ AI
ตอบจากคู่มือ/ข้อมูลทางการ: 0ไม่พบในคู่มือ (ส่งต่อเจ้าหน้าที่): 0ประหยัดโดยประมาณ (฿2/คำถาม): ฿0
