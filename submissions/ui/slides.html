หัวใจของระบบ · kernel ตัดสิน 4 ทาง

คำถามหนึ่งข้อ → kernel เลือกทางที่ถูกที่สุด

① factual → FastPath
"กี่วัน / กี่บาท" → ตอบจากคู่มือดิบ 0 token · ตัวเลขเป๊ะ (AI ไม่แตะ)
② advice + KB → Grounded Hybrid
"แนะนำวิธี..." → KB ground + AI เรียบเรียง ลื่น + ไม่มั่ว (ข้อเท็จจริงจาก KB)
③ KB ไม่ตรง → Abstain
confidence ต่ำ → บอกตรง ๆ + ส่ง staff ไม่ดันตอบผิด (เก็บ gap log)
④ personal → Intake
"login ไม่ได้" → เก็บ ชื่อ/ID/ระบบ/อาการ ครบก่อนส่ง staff
💰 LLM path = Local AI (Gemma/Typhoon) ได้ — 0 ค่า token, ไม่ส่งข้อมูลออก
kernel คัด ~80% ก่อน → ส่วนที่เหลือเบาพอให้ local model รับไหว · เครื่อง local เชื่อม Pages ผ่าน tunnel
ไม่มีจุดที่ผู้ใช้ตัน — ตอบได้ก็ตอบ (เป๊ะ/ลื่น) · ตอบไม่ได้ก็ส่งคนอย่างมีโครงสร้าง

Reflex Kernel ตัวจริง รันในเบราว์เซอร์ (WebAssembly)

🦀 Rust kernel → WebAssembly
  • algorithm เดียวกับฝั่ง server เป๊ะ (sigmoid gate θ=0.72, seeded weights)
  • ไม่มี backend · ไม่มี network call · ข้อมูลไม่ออกจากเครื่องผู้ใช้
  • พิมพ์งาน → เห็น route decision + BLAKE3 proof ภายในไมโครวินาที
  • แชร์เป็น URL เดียว กรรมการ/ผู้ใช้ทั่วไป "กดลองได้เลย"

Self-learning: ยิ่งใช้ ยิ่งคัด AI แม่นขึ้น

👍 ตอบถูก → reward +

👎 ตอบผิด → reward −
