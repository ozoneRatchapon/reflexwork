# เงินสงเคราะห์และการช่วยเหลือนักศึกษา

คำค้นภาษาอังกฤษ: เงินสงเคราะห์ ขาดแคลนทุนทรัพย์ ช่วยเหลือ financial assistance
หน้าสวัสดิการมีลิงก์หลักเกณฑ์การจ่ายเงินสงเคราะห์นักศึกษา มหาวิทยาลัยมหิดล พ.ศ. 2566:
https://graduate.mahidol.ac.th/download/current-student/Welfare/payment2566.pdf
ต้องอ่านหลักเกณฑ์ให้ตรงเหตุและสอบถามผู้รับผิดชอบ ไม่ถือว่าเป็นทุนการศึกษาทั่วไปหรืออนุมัติให้ทุกคน รอบนี้ไม่ได้อ่าน PDF นี้จึงไม่ระบุวงเงิน เอกสาร หรือกำหนดส่ง
คำขอช่วยเหลือเฉพาะบุคคลต้องให้เจ้าหน้าที่ตรวจสอบ ไม่สร้าง Ticket หรือแจ้งอนุมัติเอง และไม่ขอเอกสารการเงินหรือประวัติอ่อนไหวในแชททั่วไป
