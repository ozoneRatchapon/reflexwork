## เข้าระบบ/ล็อกอินไม่ได้ ลืมรหัสผ่าน (WE Mahidol / Student Card App / ระบบมหาวิทยาลัย)

คำค้นภาษาอังกฤษ: login cannot sign in forgot password reset account we mahidol student card app university email server error 02-849-6022

ระบบของมหาวิทยาลัย (เช่น WE Mahidol, Student Card App, e-Thesis, ระบบบัณฑิตวิทยาลัย) ใช้บัญชี university email เข้าระบบ หากรหัสผ่านผิดหรือจำไม่ได้ ให้ตั้งรหัสใหม่ที่ account.mahidol.ac.th (กด Forgot password) แล้วลองล้างแคช/คุกกี้หรือเปิดในโหมด Incognito หากรีเซ็ตแล้วยังเข้าไม่ได้ หรือพบ Server Error ให้ติดต่อกองไอที โทร 02-849-6022 หรืออีเมล account@mahidol.ac.th โดยแจ้งชื่อ-สกุล รหัสนักศึกษา/username ชื่อระบบ และแนบภาพหน้าจอ error เพื่อให้เจ้าหน้าที่ตรวจสอบและปลดล็อกบัญชีได้เร็วขึ้น
