# หลักสูตรขอเทียบเคียงกิจกรรม Soft Skills อย่างไร

คำค้นภาษาอังกฤษ: หลักสูตร เทียบเคียง Soft Skills reflection ชิ้นงาน
ประกาศ พ.ศ. 2569 ข้อ 6.1 ให้หลักสูตร/ส่วนงานจัดทำโครงการเทียบเคียงผ่านระบบ Soft Skills Online ของบัณฑิตวิทยาลัย ไม่ต้องขออนุมัติโครงการล่วงหน้า โครงการที่อนุมัติแล้วใช้เทียบเคียงได้ไม่เกิน 2 ปีการศึกษา
นักศึกษาต้องส่งชิ้นงานหรือผลงานที่สอดคล้องกับกิจกรรม เช่น Reflection Writing ซึ่งไม่เคยใช้เพื่อวัตถุประสงค์อื่น เช่น ส่งรายวิชาหรือทำซ้ำมาก่อน ส่วนงาน/หลักสูตรเป็นผู้ตรวจสอบและรับรอง ไม่ใช่เพียงลงชื่อเข้าร่วมแล้วถือว่าผ่าน
รายละเอียดการนับชั่วโมงอิงข้อ 5.1 โดยอนุโลม การอนุมัติจริงเป็นของผู้รับผิดชอบ ระบบแชทไม่สามารถอนุมัติหรือตรวจชิ้นงานแทนได้
