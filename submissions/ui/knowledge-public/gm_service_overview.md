# งานกิจการนักศึกษามีบริการอะไรบ้าง

คำค้นภาษาอังกฤษ: กิจการนักศึกษา สวัสดิการ กิจกรรม ทุน student affairs welfare
หน้าบริการเชื่อมไปยัง 7 เรื่อง: ประกาศการตรวจสุขภาพ, ให้คำปรึกษาด้านสุขภาพใจ, สวัสดิการนักศึกษา, ทุนการศึกษา/รางวัลวิทยานิพนธ์, กิจกรรมพัฒนานักศึกษา, Soft Skills และการขึ้นทะเบียนบัณฑิต/ฝึกซ้อมรับปริญญาบัตร/ใบปริญญาบัตร
หน้านี้เป็นสารบัญบริการ ไม่ใช่หลักฐานกำหนดการหรือคุณสมบัติทั้งหมด ต้องอ่านประกาศปลายทางให้ตรงเรื่องและปี ไม่ใช้กำหนดการลงทะเบียนเรียนแทนกำหนดกิจกรรมหรือสมัครทุน
