# Shuttle Bus และ Salaya Link ดูตารางที่ไหน

คำค้นภาษาอังกฤษ: รถรับส่ง Shuttle Bus Salaya Link ตารางรถ เดินทาง
หน้าสวัสดิการเชื่อมตารางและข้อมูลรถสองบริการ:
- Shuttle Bus ระหว่างวิทยาเขต: https://op.mahidol.ac.th/ga/shuttle-bus/
- Salaya Link: https://www.music.mahidol.ac.th/salayalink/
เป็นคนละบริการ ต้องเลือกให้ตรงเส้นทาง ตรวจวันและตารางล่าสุดจากผู้ให้บริการ รอบนี้ยังไม่ได้อ่านตารางเที่ยวรถและอัตราค่าโดยสาร จึงไม่แต่งเวลาออกหรือรับรองว่าฟรี
