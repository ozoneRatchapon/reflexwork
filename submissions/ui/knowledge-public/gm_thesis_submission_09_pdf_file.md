## ไฟล์ PDF สำหรับส่งรูปเล่มต้องเตรียมอย่างไร ขนาดเท่าไร
คำค้นภาษาอังกฤษ: PDF file maximum size 25 MB PDF/A embedded fonts scanned password electronic thesis upload

ตามประกาศต้องรวมรูปเล่มฉบับสมบูรณ์เป็น PDF ไฟล์เดียว ใช้มาตรฐาน PDF/A ฝังฟอนต์ทั้งหมด และให้ข้อความกับภาพอ่านและพิมพ์ได้ชัดเจน ส่วน FAQ ของหน่วยงานระบุเพิ่มเติมว่าไม่ใช้ไฟล์สแกน ไม่ใส่รหัสผ่าน และขนาดไม่เกิน 25 MB ข้อจำกัด 25 MB เป็นข้อมูลจาก FAQ ไม่ใช่ตัวเลขที่พบในข้อ 5.1 ของประกาศ PDF ที่ตรวจ ควรตรวจข้อกำหนดระบบปัจจุบันก่อนอัปโหลด และไม่ใช้ข้อจำกัดนี้แทนขนาดไฟล์ที่ระบบแชทของเรารับได้

อ้างอิงหลัก: https://graduate.mahidol.ac.th/storage/IT-SERVICE/Announce/PR07283.pdf (7–8 ข้อ 5.1; ข้อจำกัดขนาดและไฟล์สแกนจาก FAQ 34)
FAQ หน่วยงาน: https://grad-as.my.canva.site/gradas-website หมายเลข 34 (faq-pdf-file)
