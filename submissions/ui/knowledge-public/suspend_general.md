## บุคคลทั่วไปแก้ไขที่อยู่ในหนังสือรับรอง MAP-C ทำอย่างไร

คำค้นภาษาอังกฤษ: map-c general certificate address edit profile

เข้าสู่ระบบบุคคลทั่วไป (MAP-2021) > กด Edit profile > กรอกที่อยู่ที่ต้องการให้ปรากฏในช่อง Workplace แล้วดาวน์โหลดหนังสือรับรองใหม่
