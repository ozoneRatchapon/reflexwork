# สมัครกิจกรรมและตรวจผล Soft Skills ได้ที่ไหน

คำค้นภาษาอังกฤษ: ตรวจชั่วโมง Soft Skills profile ใบประกาศ certificate กิจกรรมไม่ครบ
หน้า FAQ ระบุว่าตรวจจำนวนทักษะที่ผ่านได้ใน Profile ของนักศึกษาที่ Student Service System และมีทางเข้าจากเว็บ Soft Skills
หน้ากิจกรรม: https://graduate.mahidol.ac.th/softskills/th/projectlist.php
แจ้งปัญหาบันทึกกิจกรรมไม่ครบ: https://graduate.mahidol.ac.th/softskills/th/report.php
กิจกรรมออนไลน์ MUCE: https://muce.mahidol.ac.th/
แชทนี้ยังไม่ได้เชื่อมบัญชีนักศึกษา จึงตรวจผลสะสมส่วนตัวหรือแก้ข้อมูลกิจกรรมไม่ได้ ไม่ขอรหัสผ่านในแชท
ข้อจำกัด: FAQ เดียวกันยังมีเกณฑ์เก่าเรื่อง 4 ทักษะเพื่อจบ ใช้ FAQ นี้เฉพาะช่องทางตรวจผล ไม่ใช้ยืนยันเกณฑ์สำเร็จการศึกษาแทนประกาศ 2569
