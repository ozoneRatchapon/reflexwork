# ช่องทางให้คำปรึกษาด้านสุขภาพใจ

คำค้นภาษาอังกฤษ: เครียด สุขภาพใจ ปรึกษาใจ mental wellbeing counseling
หน้ากิจการนักศึกษามีหัวข้อให้คำปรึกษาด้านสุขภาพใจ เชื่อมไปยังโปสเตอร์บริการ:
https://graduate.mahidol.ac.th/assets61/img/menta2025l-01-Th.jpg?v=1.5
วันเวลา เบอร์โทร และการนัดหมาย ดูได้จากโปสเตอร์ในหน้านี้ หรือสอบถามงานกิจการนักศึกษา
เป็นข้อมูลนำทางบริการ ไม่ใช่การบำบัดหรือการประเมินภาวะสุขภาพ และไม่ต้องส่งประวัติสุขภาพละเอียดในแชท
