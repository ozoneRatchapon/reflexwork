## ขอหนังสือส่งตัวกลับไปปฏิบัติงาน ณ ต้นสังกัด

คำค้นภาษาอังกฤษ: return to work letter bd24 government

ยื่นคำร้อง บฑ.24 สำหรับนักศึกษาที่เป็นข้าราชการหรือพนักงานรัฐวิสาหกิจที่ลาศึกษาต่อ ที่ต้องการให้บัณฑิตวิทยาลัยทำหนังสือส่งตัวกลับไปปฏิบัติงาน ยื่นผ่านระบบ e-document
