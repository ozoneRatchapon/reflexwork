## เริ่มสมัครเข้าศึกษาระดับบัณฑิตศึกษาอย่างไร
คำค้นภาษาอังกฤษ: สมัครเรียน สมัครปริญญาโท ปริญญาเอก apply application steps

เลือกหลักสูตรจากหน้าหลักสูตรที่เปิดรับสมัคร ตรวจคุณสมบัติของหลักสูตรและรอบที่ต้องการ จากนั้นลงทะเบียนผู้สมัคร เข้าระบบ กรอกใบสมัคร ส่งเอกสาร และชำระค่าสมัครภายในกำหนดของรอบนั้น เมื่อผ่านการพิจารณาให้ดำเนินการสอบ/สัมภาษณ์ตามวิธีคัดเลือกของหลักสูตร และรายงานตัวเมื่อได้รับสิทธิ์เข้าศึกษา

หลักสูตรที่มีอยู่ในสารบัญหลักสูตรอาจไม่ได้เปิดรับทุกรอบ ต้องตรวจประกาศรับสมัครของหลักสูตรจริง ไม่ใช้กำหนดการลงทะเบียนเรียนของนักศึกษาปัจจุบันแทนกำหนดสมัคร

ระบบสมัคร: https://graduate.mahidol.ac.th/admission-apply/
หลักสูตรที่เปิดรับ: https://graduate.mahidol.ac.th/Admission/announce/cur_open_list.php

ขอบเขต: คู่มือสาธารณะที่เก็บวันที่ 26 ตุลาคม 2569 ไม่ยืนยันว่าผู้สมัครคนใดผ่านการตรวจเอกสารหรือชำระเงินแล้ว
