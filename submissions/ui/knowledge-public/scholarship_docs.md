## ส่งเอกสารทุนและรางวัลได้ทางใดบ้าง

คำค้นภาษาอังกฤษ: scholarship document submission channel

เอกสารที่ไม่ต้องใช้ตัวจริงส่งผ่านระบบ e-Document บนเว็บไซต์บัณฑิตวิทยาลัย (เมนูนักศึกษาปัจจุบัน > ระบบส่งเอกสารของนักศึกษา). เอกสารสัญญาหรือเอกสารการเงินส่งที่อาคารบัณฑิตวิทยาลัย ศาลายา
