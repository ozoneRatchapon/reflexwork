# หอพักและบ้านมหิดลต้องดูข้อมูลที่ไหน

คำค้นภาษาอังกฤษ: หอพัก บ้านมหิดล dormitory accommodation
หน้าสวัสดิการเชื่อมข้อมูลหอพักมหาวิทยาลัย: https://op.mahidol.ac.th/sa/mahidoldorm/
มีลิงก์ประกาศชำระค่าหอพักทั้งภาคต้นปีการศึกษา 2569 สำหรับชั้นปีสูง และภาคปลายปีการศึกษา 2567 สำหรับผู้พักเก่า ต้องแยกกลุ่มและปี ไม่ใช้ประกาศเก่ายืนยันวันชำระปัจจุบัน
ยังไม่ได้ตรวจประกาศค่าหอทุกฉบับหรือจำนวนห้องว่าง จึงต้องเปิดหน้าหอพัก/ติดต่อผู้ดูแลก่อน ไม่รับรองสิทธิได้หอหรือราคาเฉพาะราย
