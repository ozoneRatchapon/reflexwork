## ต้องอัปโหลดเอกสารอะไรในการส่ง e-Thesis
คำค้นภาษาอังกฤษ: upload two files complete e-thesis PDF Turnitin originality report submission ID word count similarity source

ประกาศกำหนดให้ส่งรูปเล่ม PDF ฉบับสมบูรณ์และแนบรายงานตรวจการคัดลอกผลงาน โดยเว้นการลงนามในหน้าเสนอและหน้าอนุมัติไว้ก่อน FAQ ระบุไฟล์ 2 ส่วน คือ e-Thesis ตั้งแต่หน้าปกถึงประวัติผู้วิจัย และ Turnitin Originality Report ที่มีหน้าปกแสดง Submission Date, Submission ID, Word Count พร้อมหน้าผลแสดง Similarity Index/Similarity by Source หลังแนบให้กด Submit และติดตาม Status การเลือกไฟล์เฉย ๆ ยังไม่ใช่หลักฐานว่าระบบได้รับเอกสารแล้ว
