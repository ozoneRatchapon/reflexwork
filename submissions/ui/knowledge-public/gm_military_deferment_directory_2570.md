# ค้นประกาศผ่อนผันทหารประจำปี 2570

คำค้นภาษาอังกฤษ: ผ่อนผันทหาร เกณฑ์ทหาร 2570 military deferment
หน้าสวัสดิการเชื่อมประกาศผ่อนผันเข้ารับราชการเป็นทหารกองประจำการ ประจำปี 2570 ที่:
https://op.mahidol.ac.th/sa/2026/27890/
รอบนี้ตรวจชื่อและลิงก์ในหน้าสวัสดิการ ยังไม่ได้อ่านประกาศปลายทาง จึงไม่ระบุวันส่ง รายการเอกสาร หรือผู้มีสิทธิแทนประกาศ นักศึกษาต้องตรวจปีและเงื่อนไขกับงานกิจการนักศึกษาของส่วนงาน
ปี 2570 ของประกาศผ่อนผันไม่ใช่ปีการศึกษาการรับสมัครหรือกำหนดลงทะเบียน
