# ติดต่องานกิจการนักศึกษาและเรื่อง Soft Skills

คำค้นภาษาอังกฤษ: ติดต่อ งานกิจการนักศึกษา LINE contact student affairs
หน้าบุคลากร Soft Skills ระบุงานกิจการนักศึกษาและพัฒนาเครือข่าย LINE @451pslqw:
https://line.me/ti/p/~@451pslqw
หน้าเดียวกันแยกงานบริการสร้างเสริมศักยภาพทุนมนุษย์ออกเป็นอีกหน่วยงาน และหน้า FAQ ระบุผู้ให้ข้อมูล Soft Skills เป็นงานบริการสร้างเสริมศักยภาพทุนมนุษย์ จึงไม่เหมารวมเจ้าหน้าที่ทุกเรื่องเป็นหน่วยเดียวกัน
ดูหน่วยงาน/ผู้รับผิดชอบที่หน้าบุคลากร และหากเป็นปัญหาบันทึกผลกิจกรรมใช้ช่องทางแจ้งปัญหาจากเว็บไซต์ Soft Skills ไม่เดาเบอร์ต่อหรือเวลาทำการของแต่ละบุคคล
