04 / 09
การประยุกต์ใช้ AI + Kiro

สร้างด้วย Kiro · ใช้ AI อย่างคุ้มค่า

🧠 Kiro spec-driven เต็มรูปแบบ
  • 3 specs: requirements → design → tasks (learning-loop · distributable-kernel · voice)
  • steering files คุมทุก session (product · tech · structure)
  • hooks + CI ตรวจทุก commit · .kiro/ อยู่ในรีโป public
💡 AI เฉพาะที่จำเป็น
  • เรียก AI เฉพาะคำถามที่ตัวคัดกรองตัดสินว่าคลุมเครือจริง (~20%)
  • บังคับ system prompt "ห้ามแต่งนอกคู่มือ" (grounded)
  • รองรับหลาย provider: Gemini · Amazon Bedrock · local Typhoon
AI ไม่เคยเป็นแหล่งข้อเท็จจริง — ตัวเลข เบอร์ วันที่ มาจากคู่มือเสมอ AI แค่เรียบเรียง
05 / 09
ความพร้อมใช้งานจริง (Implementation Readiness)

ไม่ใช่ prototype — live บน production วันนี้

✅ พร้อมแล้ววันนี้
  • Rust → WebAssembly รันในเบราว์เซอร์ 100% · 0 backend
  • ข้อมูลไม่ออกนอกเครื่อง — ตรงกับ PDPA โดยดีไซน์
  • production-hardening: staff auth · D1 backup · tunnel token
  • 11 unit tests + CI · kernel live บน production
  • วัดจริงบนคู่มือ 440 หัวข้อของอีกทีมในมหิดล: ค้นถูก recall@1 94% · in-top-3 100% · ปฏิเสธคำถามนอกคู่มือ 5/5
🌐 reflexwork.pages.dev
🔁 ยิ่งใช้ยิ่งฉลาด (ไม่ retrain)
  • ตอบไม่ได้ → บันทึก gap (ปิดบัง PII)
  • 👎 → ลด confidence หัวข้อนั้นเอง
  • AI ร่างคำตอบ → คนอนุมัติ → คู่มือใหม่
  • ปรับคู่มือ ไม่ปรับ weights = คง 0-token
ตัวเลขวัดจริง ไม่ใช่ประมาณการ — รันบนคู่มืออิสระที่ระบบไม่เคยเห็น · kernel เดียวรันทั้ง server (native) และเบราว์เซอร์ (WASM) ตรงกัน bit-for-bit
