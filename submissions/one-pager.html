Problem → Solution

แชตบอต LLM เรียก model (เสียเงิน + ตรวจสอบไม่ได้) กับ ทุก คำถาม ทั้งที่ ~80% เป็นคำถามซ้ำ/FAQ. ReflexWork คัดคำถามซ้ำไป FastPath ที่ฟรี+ตรวจสอบได้ ส่ง AI เฉพาะ ~20% ที่ยากจริง — ลดค่า token 60–80% โดยยัง audit ได้และ PDPA-friendly

คำถาม ──► Reflex Kernel (sigmoid gate, ~µs, BLAKE3 proof) ├─ factual → FastPath · 0 token · เป๊ะ ├─ advice → grounded hybrid (KB + AI เรียบเรียง · ไม่แต่งนอกคู่มือ) ├─ off-corpus → abstain → เจ้าหน้าที่ (ไม่มั่ว) └─ personal → intake → เก็บข้อมูลก่อนส่งเจ้าหน้าที่
