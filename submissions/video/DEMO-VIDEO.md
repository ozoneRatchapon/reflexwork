# Submission demo video — reflexwork-demo.mp4

The single ≤5-minute demo required by the AI Development Challenge (actual
length ~59s). Structured Problem → Solution → AI/Kiro → Prototype → Impact:

1. **Problem** — LLM chatbots pay the model for every question (~80% are repeats).
2. **Solution** — the 18s motion explainer: a filter in front of the LLM,
   the 4-way decision, the learning loop (with sound).
3. **AI + Kiro** — spec-driven build; AI called only when needed, grounded.
4. **Prototype** — the real 20s screen recording of the live chatbot:
   FastPath at 0 token + BLAKE3 proof, abstain, the dashboard audit trail.
5. **Impact** — 60–80% AI-cost cut, auditable, PDPA-safe, federated across MU.

Built by concatenating the brand explainer (ffilms kit) + the live screen demo
with on-brand Thai caption cards (rendered via Playwright, Anuphan font).
Real server + WASM in the prototype segment — no mocks.
