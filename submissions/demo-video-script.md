> นี่คือการใช้ AI อย่างคุ้มค่า ไม่ใช่เรียกทุกครั้ง"

## ฉาก 4 — Prototype สาธิตสด (2:30–4:00)

**ภาพ:** terminal เต็มจอ — demo แบบ **interactive** (พิมพ์คำสั่งสด เห็นผลทันที)
ไฮไลต์ด้วยกรอบสีตอน output สำคัญโผล่

**คำสั่งที่รันในวิดีโอ (ปลอดภัย ไม่แตะเครือข่าย):**
```bash
# 1) สถานะ kernel — local ล้วน
reflex-agent status

# 2) route งานจริงหนึ่งงาน → เห็น decision + BLAKE3 proof ทันที (ไม่เสีย token)
reflex-agent route --category ComplianceCheck \
  --input "Review PDPA documents for Q3 and flag violations"

# 3) ลองอีกงาน เพื่อโชว์ว่าเร็วและได้ proof คนละตัว
reflex-agent route --category DataQuery --input "count student records"

# 4) benchmark (ถ้ามีเวลา)
cargo bench --bench policy_routing
```

**พูด (สคริปต์) — บรรยายทับ output:**
> "มาดูของจริงครับ — demo นี้ **โต้ตอบได้** พิมพ์งานเข้าไปแล้วเห็นผลทันที
>
> *(รัน `route` งานแรก)* ผมส่งงานตรวจเอกสาร PDPA เข้าไป — kernel ตัดสินใจเป็น
> **FastPath ในระดับไมโครวินาที ต้นทุน 0 token** และผนึกเป็น **BLAKE3 proof**
> ที่ตรวจย้อนหลังได้
>
> *(รัน `route` งานที่สอง)* ลองอีกงาน — เร็วเหมือนเดิม ได้ proof คนละตัวตามเนื้องาน
>
> *(ชี้ที่ Audit note)* และนี่คือหัวใจ: **รันงานเดิมซ้ำ ได้ proof เดิมเป๊ะ** —
> นี่คือ accountability ที่ LLM แบบ black-box ให้ไม่ได้
>
> *(ถ้ามีเวลา โชว์ benchmark)* benchmark วัดสด: การตัดสินใจใช้ ~12 นาโนวินาที
> เทียบกับ LLM ที่ใช้หลักร้อยมิลลิวินาที — เร็วกว่าหลักล้านเท่า"

**หมายเหตุการอัด:**
- ใช้ `reflex-agent route` ไม่ใช่ `smoke-test` — `route` ไม่ต้องมี Solana keypair
  และไม่ยิงเครือข่าย จึง **ไม่พังตอนอัด offline** และตรงกับ narrative audit trail
- อัดล่วงหน้าแล้วตัดต่อให้กระชับได้ ถ้าไม่อยากพิมพ์สด
